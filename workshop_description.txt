[For Stellaris 4.6.*]

[h1][b]Welcome to More Picks & Points "FLEX EDITION"[/b][/h1]
This is the Flex Edition of [i][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2034226393]"More Picks & Points: Traits|Civics|Ethics" older versions[/url][/i] or just [i]MPP[/i]. This edition offers you the freedom to customize the mod settings without manually editing any files, thanks to our optional Flex(ible) Script tool. Just download it and run it.
(Note: "Flex" in this edition stands for "Flexible" and not any other possible meaning. The goal is to provide customization options, not to imply anything else.)

[h2]• MOD DESCRIPTION •[/h2]
This mod provides players (and NPCs) with expanded freedom and realism when creating a new empire. It offers increased trait points, ethics, and civic picks. Whether you're looking to craft a unique civilization or just experimenting with different combinations, this mod is designed to enhance your Stellaris empire-building experience and user interactions by improving the diversity of alien species and ecosystems, enhancing biological realism.

[b]Vanilla Values:[/b]
- [i]ETHOS_MAX_POINTS[/i]: 3
- [i]GOVERNMENT_CIVIC_POINTS_BASE[/i]: 2
- [i]Mechanical/Robot Trait Points[/i]: 0
- [i]Machine Trait Points[/i]: 1
- [i]Biological Trait Points[/i]: 2
- [i]Max Mechanical/Robot Traits[/i]: 4
- [i]Max Machine Traits[/i]: 5
- [i]Max Biological Traits[/i]: 5
- [i]Leader trait tweaks[/i]: disabled

[b]Standard (Mod Default Preset) Values:[/b]
- [i]ETHOS_MAX_POINTS[/i]: 5
- [i]GOVERNMENT_CIVIC_POINTS_BASE[/i]: 5
- [i]Mechanical/Robot Trait Points[/i]: 1
- [i]Machine Trait Points[/i]: 4
- [i]Biological Trait Points[/i]: 5
- [i]Max Mechanical/Robot Traits[/i]: 5
- [i]Max Machine Traits[/i]: 8
- [i]Max Biological Traits[/i]: 8
- [i]Leader trait tweaks[/i]: disabled

[b]Custom Values:[/b]
With the [b][url=https://github.com/hubertdungen/Stellaris_flexScript]flexScript[/url][/b], you can freely customize the above values to your preference.


[h2]• WHAT'S NEW IN THE FLEX EDITION? •[/h2]
The [b]FLEX EDITION[/b] introduces a revolutionary way to tweak the mod's settings. With the [b][url=https://github.com/hubertdungen/Stellaris_flexScript]flexScript[/url][/b], you can:
[list]
[*]Set the mod to vanilla default values.
[*]Use the standard or beast presets (similar to the previous STANDARD and BEAST editions).
[*]Fully customize the points and picks to your liking.
[*]Prepare MPP for server gameplay.
[*]Upload a tested Workshop build through SteamCMD.
[/list]
[b][url=https://github.com/hubertdungen/Stellaris_flexScript]flexScript[/url][/b] is open source and was developed in Python. You can easily check its code at our GitHub repository.


[h2]• HOW TO USE THE FLEXSCRIPT •[/h2]
[olist]
[*]Download the latest release at the [b][url=https://github.com/hubertdungen/Stellaris_flexScript/releases]Releases Page[/url][/b].
[*]Follow the Readme.md file at [b][url=https://github.com/hubertdungen/Stellaris_flexScript]flexScript[/url][/b].
[*]Run the script, and follow the on-screen prompts to customize your mod settings.
[/olist]


[h2]• HOW TO UPDATE MPP •[/h2]
With FS, you don't have to wait for the mod to be updated; you can update it yourself whenever Stellaris gets a new version. Just follow these steps:
[olist]
[*]Run FS and let it check all folders and files to ensure everything is in place.
[*]Choose option 6: UPDATE. If you're in SERVER MODE, deactivate it before proceeding.
[*]Wait for the update to complete.
[/olist]

[h2]• EASIER MULTIPLAYER SETUP •[/h2]
Hosting a multiplayer game with friends? Flex Script simplifies the process. FS's server mode option helps all players keep identical mod settings, reducing the risk of desyncs or compatibility issues. Remember to test online games after customization, and [i]do let us know[/i] if you encounter any issues. Read more about this process at [b][url=https://github.com/hubertdungen/Stellaris_flexScript]Readme[/url][/b].
Happy gaming!


[h2]• WARNING •[/h2]
Please note that this mod also alters the picks and point limits for NPC Empires. This is not intended to function as a [i]Cheat Mod[/i]. Rather, these changes enhance the diversity of traits across different species and empires, both player-created and AI-controlled. The aim is to create a more enriching, realistic, and intense gameplay experience. Obviously this has an impact on balance. This can either make your game harder or easier depending on the species you are creating.


[h2]• COMPATIBILITY •[/h2]
This version targets the Stellaris 4.6.* compatibility line (checked against the vanilla 4.6.0 files). Please note that the STANDARD, BEAST, and LITE versions are no longer maintained. Instead, all the features have been integrated into this FLEX EDITION for a more streamlined and user-friendly experience, and also helping us to maintain this mod in an easier and more autonomous way.

This mod overrides define and species archetype values, so it may conflict with other mods that change trait points, ethics, civics, or species archetypes.


[h2]• KNOWN ISSUES •[/h2]
[list]
[*]FlexScript "Update" copies current vanilla file structure into the MPP files, so it can increase incompatibility with other mods that alter the same files.
[*]Occasionally, running the Flex Script might trigger Windows Defender due to its interaction with mod files and the installed files of Stellaris. Rest assured, this script is open source and you can verify its harmless nature by checking the code on our GitHub repository.
[*]Some mod incompatibilities may arise when using other mods that also modify trait points, ethics, civics, species archetypes, or related species creation rules.
[*]Leader trait tweaks were removed until the current leader trait/officer issue has a safe fix.
[/list]
